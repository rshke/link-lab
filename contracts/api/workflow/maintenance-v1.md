# 工作流设备维护内部 API v1

`GET /v1/maintenance` 返回设备维护快照及本工作流 `workflowReserved` 标记。`POST /v1/maintenance/actions` 接受平台已校验的维护请求，字段和响应见平台 `maintenance-v1.md`。

维修与实验共用单设备资源预留。实验运行中或结果 unknown 时拒绝维护；维修执行中拒绝新实验。通信失败保留预留，只允许完全相同的待确认维修请求重试确认；不同请求不能释放预留。确认动作已响应后释放维修预留，但设备仍不可用于实验，直到维护状态为 ready。

实验准入会查询设备维护状态；非 ready 状态在派发前拒绝。模拟器仍在执行入口再次检查，避免管理端注入故障与派发之间的竞态。维护操作不改变旧实验的状态、结果和样品。
